# art-src — 캐릭터 원본 시트

여기는 **AI로 뽑은 원본 그림**을 두는 곳이다. 게임이 읽는 곳이 아니다.
게임이 읽는 것은 `public/img/<id>.png`(400×400·투명)이고, 그건 여기서 **가공해서 나온다.**

## 왜 원본을 남기나

**다시 못 뽑는다.** 같은 프롬프트를 넣어도 같은 그림이 안 나온다.
원본을 잃으면 나중에 "조금 더 크게 다시 자르자"·"표정만 바꾸자"를 할 수 없고 처음부터 다시 그려야 한다.
그래서 원본은 버리지 않는다.

## 폴더 규칙

```
art-src/YYYY-MM-DD_설명/          한 번의 생성 묶음
  sheet.png                       뽑은 원본 (라인업 시트든 낱장이든)
  cut/<id>.png                    시트에서 잘라낸 낱장 (가공 전)
  NOTES.md                        어떤 프롬프트로 뽑았는지 · 쓸지 말지
```

## 원본 → 게임 자산

```bash
python3 scripts/process-char-art.py art-src/<묶음>/cut/<id>.png public/img/<id>.png
```
배경 제거(코너 flood-fill) · 여백 정리 · 400×400 리사이즈를 한 번에 한다.
**`<id>` 철자는 코드가 찾는 그 철자여야 한다** — `public/chars.js`·`public/shop.js`·`server.js`의 `CHAR_IDS`.

## 지난 원본들

7/21·7/22·8/4에 뽑은 시트 10장이 아직 **저장소 루트에** `ChatGPT Image ....png` 이름으로 있다(17MB).
정리하려면 여기로 옮기면 된다. 다른 세션이 그 파일을 보고 있을 수 있어 자동으로 옮기지는 않았다.
