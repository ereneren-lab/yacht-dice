## 1. 제작 목표

신규 유입자가 13종 중 무엇을 고르든 **"이건 몇 분짜리 게임"** 이라는 예상을 클릭 전에 갖게 한다. 규칙 화면 하나 늘리지 않고, 허브 카드·셋업 화면·인게임 진행 표시 세 지점에 같은 기준의 짧은 문구만 추가한다.

## 2. 적용 전략

상위 전략 문서의 원칙 4 "화면 밖에서 기대치를 미리 준다"와 원칙 5 "통계적 확신보다 구조적 개연성"을 그대로 따른다. 단, **작업 도중 엔진 담당(재성님)이 섯다·인디언 포커의 종료 조건을 실제로 고쳤고**, 그 결과 재측정치가 처음 브리프의 값과 크게 달라졌다(섯다 15분40초→3분51초, 인디언 포커 6분03초→1분31초, 로컬 기본 인원 기준). 이 문서는 **최종 재측정치를 반영한 최신 버전**이다.

## 3. 크리에이티브 방향

- 장식 없음. 이모지 1개 + 텍스트로 "속도감"을 즉시 스캔되게 한다.
- 4단계 아이콘 체계로 13종을 분류해 "어떤 게임이 짧고 긴지"를 그림만 봐도 알 수 있게 한다.
- 최장값은 어디에도 노출하지 않는다(상위 전략 9-3절 — 불안감만 준다). 중앙값 기반 구간만 쓴다.
- 옵션에 따라 길이가 크게 달라지는 두 게임(섯다·인디언 포커)은 숫자 뒤에 "(기본 설정 기준)"을 붙여 단정하지 않는다.

### 5-3. 기본 인원과 측정 인원 불일치 — premise

- **[미확정]** 라이어 다이스: 셋업 기본 선택은 3인(`ld.html` `data-n="3"` opt on)이지만 오케스트레이터가 지정한 표기 기준 인원은 4인이다. 실제 3인 판은 이보다 짧을 가능성이 높다.
- **[미확정]** 윷놀이: 셋업 JS 기본값은 2인(`cfg={n:2,...}`)이지만 표기 기준 인원은 4인이다. 2인 판은 이보다 훨씬 짧을 수 있다(미측정).
- 이 두 게임의 셋업 문구에는 "(4인 기준)"을 명시해 단정하지 않게 했다. 나머지 게임은 셋업 기본 인원과 측정 인원이 일치한다(직접 확인).

### 7-2. 구현 원칙

- 모든 셋업 문구는 **인라인 스타일**(`font-size:12px;font-weight:700;color:var(--muted)`)로 넣었다. 각 파일의 `<style>` 블록을 건드리지 않아 기존 레이아웃·캐스케이드에 영향이 없다.
- `index.html`의 `.pill`은 기존에 11px(12px 미만)이었다. 새로 추가하는 시간 pill만 `.pill.time` 수식자로 12px을 명시해 **새 텍스트가 floor 미달이 되지 않게** 했고, 기존 12개 pill의 크기는 건드리지 않았다(범위 밖 — 하단 미확정 참고).
- 섯다·인디언 포커의 `const cfg` 기본값·엔진 생성부, CORE 마커 블록은 전혀 손대지 않았다. `renderNote()`/`render()`는 CORE 마커 **바깥**의 클라이언트 렌더 코드다(`npm run check:drift`로 확인됨 — core와 무관).
- 두 게임의 인게임 문구는 엔진이 노출하는 값(`S.handNo`, `S.ante`)만 읽는다. 앤티 인상 주기·배율 같은 core 상수는 문구에 하드코딩하지 않았다 — 엔진 쪽에서 그 값을 다시 바꿔도 문구를 고칠 필요가 없다.

## 10. 미확정 사항

- **[미확정]** 라이어 다이스·윷놀이는 셋업 기본 인원과 표기 기준 인원이 다르다(5-3절). 실제 기본 인원 기준 재측정이 없어 "(4인 기준)"으로만 명시했다.
- **[미확정]** 블랙잭·바카라·하이로우 3종은 여전히 코어가 없어 실측 자체가 불가능하다(상위 전략 13절과 동일한 공백). "🔁 라운드제"는 시간 대신 구조를 알리는 것으로, 실제 평균 라운드 수·소요시간은 모른다.
- **[미확정]** 인디언 포커 셋업 문구의 "2~3분(기본 설정 기준)"은 시작칩=5(기본) 기준이다. 사용자가 10·20을 선택하면 상당히 길어질 수 있으나(과거 6분대 관측), 옵션별 정확한 값을 다시 재는 것은 이번 범위 밖이다.
- **[범위 밖]** 기존 `.pill`(11px)·`.qm` 외 허브 다른 텍스트의 12px 미만 여부는 이번에 감사하지 않았다(`audit:readable`이 허브 페이지 자체를 대상에 포함하지 않음 — 게임 인게임 화면만 검사).

## 11. 다음 제작 단계

1. 엔진 담당이 섯다·인디언 포커 값을 한 번 더 조정하면(예: 온라인 4인 별도 수치 반영, 인디언 포커 시작칩 10/20 옵션별 재측정) 6-3·6-4절 문구를 다시 대조한다.
2. `outputs/final/`로 승격할지 여부는 오케스트레이터 통합 검토 이후 결정.
